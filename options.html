▲ HN Jev Sorter

Sorts Hacker News comments into buckets as you watch, using Jev by TypeSafe.

  1. Get a Jev API key

    Create one in the TypeSafe console.

  2. Paste it here

    The key is checked with one tiny request and stored only in this browser.

  3. Open a thread and click the icon

    Pin the extension from the puzzle-piece menu, open any Hacker News comment page, click the icon, then press Run.
